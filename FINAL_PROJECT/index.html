    About This Project

    This is my final JavaScript project a math quiz game. I chose this idea because it was the first thing I ever built when I started coding as a beginner. This time I already know the process, so I wanted to come back to it and build it the right way. The player picks a difficulty level, answers math questions before the timer runs out, and gets a score at the end. Here is how I built it with JavaScript.

    1. Global Variables

    Variables like chosenLevel, score, and timer are declared at the top so every function can access and update them.

    2. Switching Between Screens

    All four screens exist in the HTML at once. I use switchFrame() to show one and hide the rest using style.display.

    3. Generating Random Questions

    generateQuiz() creates two random numbers, picks a random operator, calculates the answer, then generates wrong choices with the same digit length and shuffles them all.

    4. Rendering the Quiz

    renderQuiz() builds the HTML using template literals and injects it into the page with innerHTML.

    5. The Countdown Timer

    setInterval() counts down every second. When it hits 0 it stops with clearInterval() and moves to the next question.

    6. Handling the Player's Answer

    I use addEventListener('change', handler, { once: true }) so the player can only select once. The timer stops immediately and answers are highlighted.

    7. Closures

    handleAnswer is defined inside main() so it can access currentQuiz directly — no global variable needed.

    8. Score and Progress

    score increments on each correct answer. A dot in the header turns green or red after each question to show the player's progress.
