I chose this project because a math quiz was the first thing I ever built when I started coding, and I wanted to come back to it and build it the right way.

I built it using HTML, CSS, and JavaScript, one HTML file with multiple sections that show and hide to act like different pages, and a JavaScript file that handles the game logic like generating questions, a countdown timer, score tracking, and answer checking.

I already had experience with JavaScript so I tried to write clean and organized code with comments to make it easy to follow.
