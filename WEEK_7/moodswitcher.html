Project 7 --DOM and JS

JavaScript Questions

1. Why is textContent safer than innerHTML?

Answer: textContent is safer because it treats all content as plain text and does not execute scripts, while innerHTML parses HTML tags and can allow malicious code to run.

2. How are HTML elements connected to JavaScript variables using DOM selection?

Answer: HTML elements are connected to JavaScript variables using DOM selection methods like document.getElementById() or document.querySelector(), which find elements in the DOM and store them in variables.

3. What would happen to the text box with id="text" if I added this line to the code above it: text.textContent = "Hello!"

Answer: The existing content inside the element would be replaced, and it would display "Hello!" instead.
